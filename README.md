## Featured Project

### TuanKiet BranchFlow

A multi-branch beverage shop operations management system developed as an ongoing graduation project.

[![BranchFlow CI](https://github.com/khangba153/TuanKietBranchFlow/actions/workflows/ci.yml/badge.svg)](https://github.com/khangba153/TuanKietBranchFlow/actions/workflows/ci.yml)

**Architecture:** Layered monolithic application  
**Backend:** ASP.NET Core Web API  
**Frontend:** Blazor Web App with Interactive Server  
**Database:** SQL Server and Entity Framework Core Database First  
**Testing:** xUnit and Moq  
**Deployment:** Azure App Service and Azure SQL Database

### Completed

- JWT authentication and role-based authorization
- Branch-scoped access control
- Employee management and assignment history
- Employee status and branch transfer workflows
- Branch-specific menu API
- Responsive menu browsing with category filtering and accent-insensitive search
- Business-rule unit tests with xUnit and Moq
- GitHub Actions workflow for restore, Release build, and automated tests
- Working API and Web demo deployed to Microsoft Azure

### Currently Building

- Product size and topping customization
- Quick-note selection
- Shopping cart
- Order creation and price validation from the database

### Planned

- Menu management for administrators
- Order processing for administrators and owners
- Employee self-service profile
- Inventory management
- Payroll and operational reporting
- Audit log
